# Aturan Desain & Antarmuka SAKODE

1. **Palet Warna Resmi SAKODE**:
   - Primary Cyan: `#71CFFE`
   - Accent Purple (Konteks Tim/Kolaborasi): `#BC71FE`
   - Accent Orange (Batas Waktu/Peringatan): `#F9723B`
   - Backgrounds: `#F7FBFE` (dasar aplikasi), `#FFFFFF` (kartu/kontainer)
   - Border: `#DBE8F0`
   - Typography Teks: Utama `#172033`, Sekunder `#64748B`
   - Radius Standar: `8px` (`rounded-lg`)

2. **Tipografi & Estetika**:
   - Menggunakan font `Nunito` secara konsisten.
   - Menggabungkan struktur antarmuka profesional modern dengan sentuhan halus RPG quest board tanpa jatuh ke estetika generik.

3. **Aksesibilitas & Ergonomi (WCAG AA)**:
   - Target sentuh (touch target) tombol dan kontrol interaktif di mobile minimal berukuran `44px x 44px`.
   - Status task/badge dilarang dibedakan hanya dengan warna; wajib menyertakan teks dan ikon status yang jelas.
   - Pertahankan keyboard navigation yang dapat diakses (focus-visible ring).

4. **Standar Bahasa**:
   - Seluruh elemen UI, label form, modal, notifikasi, dan pesan error menggunakan **Bahasa Indonesia** baku dan lugas.
